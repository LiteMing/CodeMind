# 2026-04-13 区域框与关系线编辑改造总结

## 已完成

- 连线风格新增“隐藏”选项，用于隐藏层级结构连线。
- 关系线支持直接选中、右键菜单删除、箭头方向切换。
- 节点右上角新增关系锚点，可直接拖拽建立关系线。
- 关系线被选中时会显示中继圆点，可继续拖拽扩展为多叉关系。
- 文档结构新增关系枢纽点与区域框，前后端存储与校验已同步。
- 新增区域框功能：
  - 通过右键菜单进入创建模式
  - 左键拖拽圈定节点后生成区域框
  - 区域框可选中、改色、删除
  - 拖动区域框时成员节点整体联动
- 3D 视图中，属于区域框的节点会额外显示对应颜色的外圈。

## 验证

- `npm run build:web`
- `go test ./...`
- `npm test`

以上命令均已通过。

## 风险与后续建议

- 当前区域框本质是“节点分组”，边界由成员节点实时计算；若后续需要手工拉伸区域框本身，需要再补独立几何控制点。
- 多叉关系当前通过“关系枢纽点”实现，已满足继续分叉，但还没有单独的枢纽点拖拽编辑器。
- 关系线“隐藏”目前作用于层级结构连线，手动关系线仍保持可见，便于继续进行图示编辑。
