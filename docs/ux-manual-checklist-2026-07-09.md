## 使用方法

- 环境：浏览器模式 `npm run dev`（根目录，开 Vite 输出的地址；F12 可看帧率）为主，桌面壳 `wails dev` 抽查差异项（滚轮、窗口缩放、webview 行为）。
- 数据：准备①空白新图；②约 30 节点的日常图；③≥200 节点大图（AI 扩展几轮或导入 JSON）。
- 判定：勾选=通过；不通过在行尾记现象。标注【预期失败】的项是确认缺口体感严重度，失败是正常结果，记录"是否难受、多难受"。

## A. 动效与手感

- [√] A1 面板滑入滑出：开/关 设置、AI、Inspector 三个抽屉各 3 次 → 每次有 ~200ms 滑入/出动画，无闪现；快速连开连关不卡死、不重影
- [X] A2 手动建节点：Tab/Enter 连续建 10 个 → 每个有 scale+fade 出现动画；连按不掉帧、不闪
创建节点时候没有出现动画
- [X] A3 删除节点：删单节点与删带 10+ 子节点的父节点 → 有收缩消失动画；子树删除呈 stagger 错落感，无"残影节点"留在画布
删除的时候连线没有跟随节点的消失动画效果，删除时候，节点渐隐动画位置和实际位置有偏差，会往右下角挪移
- [X] A4 折叠/展开：折叠 20+ 子节点的分支 → 子节点错落收拢（40ms 间隔）、连线同步淡出；展开反向；动画期间连点折叠按钮不错乱
动画是对的，但是和前面删除节点一样，节点渐隐动画位置不对
- [√] A5 拖拽反馈三件套：拖一个节点 → ①拖起有阴影加深+轻微放大；②靠近其他节点 5px 内出现对齐辅助线；③进入可挂靠目标 40px 内目标高亮；松手有落位过渡
- [√] A6 连线 hover：鼠标悬停层级线/关系线 → 线变粗（约 4.5px）有平滑过渡；移开恢复
- [√] A7 新建关系线【预期失败】：创建一条新关系线 → 预期**无**生长动画（edge-grow 是死代码）；记录观感是否突兀
- [√] A8 编辑态：双击进入编辑、完成退出 → 记录进入/退出是否生硬（node-editing 过渡 CSS 未接线，预期偏硬）
- [？] A9 减弱动效（可选）：系统开启"减弱动态效果"后重复 A1-A4 → 动画显著缩短或消失（prefers-reduced-motion 降级生效）

## B. 画布导航

- [√] B1 滚轮缩放：连续滚动缩放 → 平滑插值无跳变；**缩放进行中反向滚动**（retarget）不闪跳；缩放中心跟随鼠标位置
- [√] B2 键盘缩放：Ctrl+加/减/0 → 平滑过渡；Ctrl+0 回到默认比例
- [√] B3 首次缩放回归项：新开一张图，第一次滚轮缩放 → 镜头不跳动（6 月修复项 b117497，防复发）
- [√] B4 平移惯性：快速拖拽画布后松手 → 有滑行衰减；滑行中再按下立即停住；滑行中滚轮缩放两者不打架
- [√] B5 Fit-to-view：触发适应画布 → ~400ms 平滑过渡到全图；在大图（200+）上依然平滑
- [X] B6 小地图：①点击小地图任意处，镜头平移居中到该处；②拖拽视口框连续导航；③增删/折叠节点后小地图实时同步（折叠的子树在小地图消失）；④hover 小地图透明度变化
拖拽小地图有问题，会有异常的镜头快速拖动跳转，且点击外围无节点区域会让镜头调往难以手动折返的可能是极远地区
- [ ] B7 3D 图谱浮层跳转：打开图谱 → 搜索节点名回车 / 双击节点 / 选中后点 Focus → 关闭浮层后主画布镜头已居中到该节点；体验记录：搜索结果**点击只选中不跳转**（需再按回车），是否别扭
- [ ] B8 主画布找节点【预期失败】：不开图谱浮层，在主画布找一个 200 节点图中的具体节点 → 预期只能靠肉眼+小地图；记录耗时和挫败感（大纲/主画布搜索缺失的体感依据）
