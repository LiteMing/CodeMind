# 2026-04-13 区域框与关系线编辑改造计划

## 目标

- 修复“关系线难以直接删除”的问题，让关系线可选中、可右键操作。
- 为关系线补充箭头方向配置，支持无箭头、单向、双向。
- 在节点右上角增加连线锚点，支持从锚点拖拽到其他节点创建关系线。
- 增加“区域框”功能：通过右键菜单进入创建流程，左键拖拽选择节点集合并生成可染色区域框。
- 让区域框处于节点与连线底层；拖动区域框时，其包含节点整体联动。
- 在 3D 视图中，为被区域框覆盖的节点渲染带颜色的外圈提示。
- 在线条风格设置中补充“隐藏/不显示连线”选项，用于隐藏层级结构连线。

## 拆分

1. 扩展文档数据结构
   - `RelationEdge` 增加箭头方向、可见性/命中辅助所需字段。
   - `MindMapDocument` 增加区域框集合。
   - Go/TS 两侧文档结构、默认值、校验逻辑保持一致。

2. 关系线交互改造
   - SVG 关系线增加可点击命中区域与选中态。
   - 右键关系线菜单支持删除、箭头方向设置。
   - 节点右上角增加锚点；从锚点按住拖拽到目标节点锚点创建关系线。
   - 关系线选中时显示中继圆点，为后续多叉扩展保留入口。

3. 区域框功能
   - 画布右键菜单新增“创建区域框”。
   - 创建后进入一次性框选模式，左键拖拽圈定节点，自动生成区域框。
   - 区域框支持选中、右键、改色、删除、拖拽联动成员节点。

4. 3D 视图补充
   - 读取区域框成员关系，为节点增加对应颜色外圈。

5. 验证
   - 构建前端与 Go 测试。
   - 人工验证关系线创建、删除、箭头方向、区域框创建与拖动、3D 外圈表现。

## 方案说明

- 区域框优先实现为“节点分组实体”，边界由成员节点实时计算，这样节点自身移动后区域框也能自动跟随，不需要额外维护几何同步。
- 关系线的“中点继续延伸成 3 叉/4 叉”本轮先补数据与交互入口：在线被选中时显示中继圆点，并允许从该圆点继续拖拽生成新的分叉关系；底层会通过“关系枢纽点”实体承接，避免继续把关系图强行限定成纯两点边。
